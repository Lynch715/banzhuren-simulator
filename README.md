# 铃响之后 · 班主任模拟器

一个无需构建工具、直接通过本地 HTTP 服务运行的高中班主任模拟游戏原型。

## 设计原则

**游戏不给自己的机制配旁白。** 玩法说明之外，任何弹窗都不会出现「N 周后它会回来找你」「把压力降到 74 以下就能解除」「等着你找他」这类系统腔或任务提示。后果只用一句具体的细节暗示，提醒只用现实里认得出的信号。数值面板照常给数字——那是班主任本子上本来就有的东西。

**没有双赢的选项。** 每个选择都会明确拿走一样东西——分数、信任、你的声望，或者你自己的健康。选项提示里写的是代价，不是收益。

**后果延迟兑现，而且到点必到。** 重大决定过一阵子会回来找你，并且带着新的两难。它不参与每周的随机抽签——只要种下了，那一天就一定会敲门；开了头的事件链也按叙事里写的间隔推进（"三周之后"就是三周之后，"一模之后"就是一模之后）。旧账没结完，新的事不会挤进来。

**时间是日历，不是关卡编号。** 三月十六号接手，六月七号高考，中间八十三天。界面上写的是「4月13日」和「距高考 55 天」，不是「第 5 周」；手记按日期归档，学生离开写的是「5月4日走的」，旧账翻出来是「两周前那个决定，现在轮到你还了」。

**学生会真的失去。** 压力连续两周高于 86，该学生永久退出这一届：故事线中断、高考缺考、班级士气重创。系统只给一次预警。

**班上 48 个人，每一个都有名字。** 徐慧是学习委员，石斛坐在最后一排，樊听雨是艺考生——43 名学生各自有身份标签、学业上限和独立的心情与压力值，花名册随时可以翻。教学与班会作用于全班；辅导、谈心、家校沟通可以指定任何一个人，不限于有剧情的那几个。

**剧情会自己找上门。** 5 名重点学生开局只是名册上的普通名字。到了特定周次（或他们的压力先失控），第一章会以事件形式登门——晚自习后站在办公室门口的影子、教务处送来的七次迟到记录、一本翻到最后一页的草稿本。这一章不消耗行动力，它不问你有没有空。之后的章节才需要你主动去推进；没推进的故事会停在半路。

**撑不住的时候，最先垮掉的是成绩。** 长期高压会让学业值持续下滑，绝大多数孩子的糟糕结局是考砸——复读、读大专、二本。真正办手续离开这个班的，一届最多两个。

**但也有例外。** 如果一个孩子一路滑到底，会有人来提醒你，一次比一次清楚：任课老师、同桌、以及他自己反常的平静。信号最多来三次。三次都被推到"等这阵子忙完"之后，会发生不可挽回的事——学生坠楼，脊髓损伤，此后靠轮椅生活。这一届剩下的每一周都会在这件事之后进行，结局也不再由排名决定。

> **内容提示：** 本作涉及高考压力下的青少年心理危机，包含自伤相关情节与不可逆的严重后果。写进来是为了让玩家认得出现实中的求助信号（成绩断崖、把珍视的东西送人、长期低落后突然的平静），而不是为了渲染。游戏开屏也有同样的提示。

**先排课表，再安排自己的时间。** 主界面是一张 5 天 × 8 节的周课表。高三早就分完科了，白天六节就在语数外综之间转（每周语文 5 节、数学 5 节、英语 5 节、综合 13 节，外加两节体育），由教务处排定，你自己的科目会高亮。晚上两节晚自习共 10 个格子完全归你——点一下就在语文／数学／英语／综合／自由活动之间切换。

每周还可以强行占用 2 节别人的课。综合是五位老师分着带的，鼠标停在格子上会告诉你这节是谁的——占陈海的还是占吴敏的，账记在各人头上，占够两节那位就来找你算。占体育课不惹老师，但全班的心情会掉。

晚自习的分配直接改写分科成绩。同一颗种子、同样的打法，只换排法：主攻数学能把数学均分推到 147 而语文掉到 98；补最弱一科则拉平成 111/116/107/237。长期偏废一科会触发拖科惩罚，四科均衡则互相带动。排得满不满则是压力与进度的交换——如果你从不用班会和家校沟通降压，晚自习就是你唯一的减压阀。

**办公室里有别人。** 八位任课老师各有性格：语文周立群带了二十六年书下学期退休，英语林岚入职第三年不敢抓早读，综合科的陈海（物理）是一班班主任、会来挖你的尖子生，许文昭（生物）说"我那部分你们随便占，反正生物就那么点分。不过话说回来，那也是分"。他们会来吐槽、抱怨被占课、提醒你某一科的课时被砍太狠，或者顺口告诉你某个学生在他课上的样子。课代表也会抱着作业本进来，问某个人的空白要不要写进名单。

**学生的四条互动线。** 每周收上来两本周记，你只来得及认真回一本——写什么会直接改变那个孩子的状态；随机学生会来敲办公室的门，为换座位、请半天假、退社团、"他们一起吃饭都不叫我"、一道题、或者一盒润喉糖；座位表 24 组同桌可以调，成绩差得多的两人坐一起好的能带差的，两个都情绪低落的坐一起会一起往下掉。

**每周 3 件事，每件都要再做一次取舍。** 上课要定讲给谁听（抓中间／拔高／补差，三种各有明确的受益人和牺牲品），班会要定开什么，备课要定备什么，辅导要定补哪一科（会读你上次考试的分科数据，标出丢分最多的那门），打电话要定怎么开口。没有一键了事的行动——一局 12 周会弹出约 120 个界面，其中 48 个需要你真的做决定。

**还有三件不占时间的事。** 翻作业本、课间转一圈、站后门听课。它们不改任何数值，只让你看见班上正在发生什么——谁的作业后三页空着，谁趴在桌上说不困就是不想动，谁一直在抄但看不出有没有在想。看不看随你，但结局会算上你花过多少心思。

**只上课能及格，但拿不到好结局。** 从不谈心、不打电话、不开班会的打法，25 局测下来 100% 落在两个冷淡结局上：

> 散会以后有个老师问你，你们班那个总坐最后一排的孩子叫什么来着。你想了很久。
> 你教完了这一届。四十八个名字你都点过，但没有一个人在毕业那天单独来找过你。

**最后一章是志愿填报。** 高考分数出来之后，游戏还没结束——你要陪着走完的每个孩子逐个决定冲、稳、保，以及要不要服从调剂。冲一冲够着了是这辈子的事，够不着又不服从调剂，就只剩复读。而这一章会把前面十二周的信任值一次性兑现：**信任够的孩子会照你说的填，信任不够的回家以后自己改了。**「我没听您的。是我自己的事。」

**家长会与家访。** 家长会是四十八个家庭坐满教室的那四十分钟，你可以从年级排名讲起、可以先讲跟分数无关的好事、也可以把话筒交给学生——你说的每句话今晚都会被复述四十八遍。家访要占掉一个休息日，但进了那个门才看得见：书桌是超市收银台旁边那张折叠桌，墙上的奖状停在两年前，画架背面写满了他自己的名字。

**班委与集体事件。** 班长、学习委员、纪律委员三个位置由你任命，称职的顶事，压不住的把整块拖下去，而且当干部本身就要占掉那个孩子的时间。集体事件另有甲流停课、暴雨预警、停电的晚自习、食堂那顿饭——全班一起摊上的事，跟个人线是不同的质感。

**不是每周都出大事。** 十个「教室一角」闲笔事件调和整体的沉重基调：储物柜里偷养的仓鼠、黑板右下角以你为主角的四格连载、广播站点给"四十八只青蛙"的歌、包浆的占卜橡皮、运动会最后那根拔河绳。它们照样没有双赢——留下仓鼠要搭上纪律，跟着听完那首歌进度就慢半拍。日历上还有两天是躲不开的：愚人节讲台上那杯沉着跳跳糖的枸杞茶，五四成人仪式上凑不齐的三封家长的信。手记的"这周的琐事"里也会混进闲笔——谁把橡皮切成两半留着高考用，哪两个同桌把桌子拼成了"学习共同体"。

**四十八个人，每人一件跟分数无关的小事。** 点开任何一个学生的档案，都有一条「班上的说法」：给每支笔起名字的、能把校长口头禅模仿到以假乱真的、下课铃响前十秒准时醒的。五名重点学生各有专属的一条——陆鸣的耳机永远只戴一边，后来你才知道，另一边是留着听课的。

**翻作业本与转走廊是真的要翻、要走。** 「翻作业本」摊开六本，点开哪本翻哪本——有人最后三页空着，有人在角落画了只猫写着"老师应该看不到这里"；「课间转一圈」给你四个地方，十分钟只够走两个，上课铃一响剩下的就只能下周再看。

**执教纪念册跨届保存。** 右上角那本册子记两样东西：15 个名场面（停电那晚的蜡烛、拔河赢了实验班、面不改色喝完跳跳糖茶、五条故事线一届走完……），和 12 种毕业结局的收集进度。没拿到的只给一句提示，答案要自己带下一届去找。

## 核心系统

- 三种任教学科、12 周行动循环、本地自动存档
- **年级八个班的真实梯队**：一班实验班、二三班重点班、四五六班平行班、八班艺术班。他们不是在原地等你——第 7 周起集体加速，第 10 周再加一档；而且**会盯着你**：只要七班的预估均分压过某个班超过 5 分，那个班下周就开始加码。每周还有一个班会传出自己的动静（"高三（2）班这周开始上晚三了""高三（6）班闹了一次集体请假，年级组通报批评"），有的往上冲，有的自己塌了
- **三条班级事件链**：早恋、打架、逃课去打游戏。角色从班上真实的名字里挑，每条跟两到三幕，第一幕的处理方式决定后面几幕的走向——拆散早恋的两个人，一模之后一个涨了十一位、一个掉了二十三位；打架先分开问清楚，才会知道对方那伙人给他起的外号全班都知道，只有你不知道
- **48 名实名学生**：每人有身份、学业上限（38–96 不等）、心情、压力与信任，全部独立演算。同一节课对不同人价值不同——基础差的跟不上，拔尖的吃不饱
- **剧情登门机制**：5 条故事线在第 2、3、5、6、8 周（或压力超过 84 时提前）主动触发，不消耗行动力
- 花名册面板按「最需要你」排序，随时可翻全班 48 人的完整数据
- 六类行动（教学 / 精准辅导 / 谈心 / 班会 / 家校沟通 / 夜间备课），**重复使用效果递减**，逼迫手段轮换
- 5 名重点学生 × **17 个分支剧情节点**：第 1 章的选择决定第 2、3 章走哪条线，同一个学生有截然不同的结尾
- **14 条后果链**：学生线与成人世界的重大决定都会回旋镖式兑现
- **14 个周事件**，不重复抽取，部分带前置条件；覆盖校长听课、家长群舆论、隔壁班挖人、排名公示、家长送礼、教研组倾轧、学生联名信、你自己的体检报告
- **心理危机三级链**：可见预警 → 最后干预窗口 → 不可逆事故。三次认真对待必定化解，三次敷衍必定出事；中途把学生压力降到 74 以下即自动解除
- **选择回执**：每个重要选择之后弹出结果面板，逐项列出实际生效的数值增减（封顶之后的真实值，不是账面值）。埋下后账时不做系统播报，只留一句具体的余韵——「你回办公室的时候，座机上有两个未接来电，是同一个号码」
- **本周小结**：每周结束汇总你做了什么、五项班级数值的变化、全班平均的升降，以及一栏「这周的琐事」——写成手记里的观察，不是待办清单
- **分科成绩**：语文 150 / 数学 150 / 英语 150 / 综合 300。每名学生有独立学科天赋，四科之和恰好等于总分；任教学科受教学水平额外带动；得分率比本人平均低 12 个百分点即触发偏科预警。考试报告含分科均分、单科最高、可展开的全班成绩分析表
- 四次阶段考试，高压学生有较大概率发挥失常，被真正接住的学生可能超常发挥
- **录取结算**：先给全班 48 人的上线分布与一本率（学校年底写进总结的那个数字），再单列重点 5 人的录取院校与专业。7 档分数线映射院校批次，每名学生带独立学业上限，跑再多课也追不平天赋差距；剧情 flag 会直接改写分数与升学路径——体育单招、强基计划、复读班、转学后异地高考都是独立结果
- 阶段考试同步给出全班上线人数估算，让十二周有可读的进度条
- 8 种毕业结局，录取名单与学生后日谈均由全局 flag 组合决定
- 原创校园场景、角色立绘图集与代码绘制 SVG 图标；桌面与手机响应式

## 平衡验证

`montecarlo.js` 跑 200 局随机通关的结果：

| 指标 | 分布 |
| --- | --- |
| 高考排名（共 8 个班） | 第 4 名 49% / 第 3 名 27% / 第 5 名 12% / 第 6 名 6% / 第 7 名 5% / 第 2 名 2% |
| 挤进年级前三 | 29%（对手加速之前是 58%，现在得真的做对事） |
| 班级均分 | 最低 481 / 中位 575 / 最高 586 |
| 事件链走完率 | 早恋 52% / 打架 40% / 逃课打游戏 33% |
| 每周界面数 | 平均 10.3 个，其中 4.0 个是决策点 |
| 全班分数落点 | 一本 58% / 二本 41% / 专科 1% |
| 剧情登门 | 5 条 100%（每局都会找上玩家） |
| 故事走完数 | 2 条 37% / 3 条 30% / 1 条 17% / 4 条 11% / 5 条 5% |
| 中途离开人数 | 0 人 100%（正常打法下几乎不会发生） |
| 后果链覆盖 | 14 条全部可达 |

五条故事线一定会来找你，但十二周的行动力不够全部走完——中位数只能走完 2–3 条。这是刻意的。

定向策略对照（这是本作想要的曲线）：

- **只顾提分**（只上课、只夜间备课，从不开班会、从不打电话）：月考一本 24 人领跑 → 一模掉到 17 人 → **高考只剩 3 人上一本（6%）**，程默滑到专科
- **全力护人**：月考一本仅 10 人垫底 → 期中 20 → 一模 23 → 高考一本率 48%，五个孩子都考进了一本以上

前者赢在开头，后者赢在终点。学生被榨干之后成绩会自己崩掉——这个交叉点就是整个数值模型想表达的东西。

心理危机链单独验证（`crisis_test.js`，极端忽视型打法）：

| 应对方式 | 结果 |
| --- | --- |
| 三次预警全部敷衍 | 3/3 颗种子均在第 6–10 周发生事故 |
| 三次预警全部认真对待 | 3/3 颗种子均未发生事故 |

## 运行

**最简单：** 双击 `铃响之后.html`。这是打包好的单文件版本，样式、脚本、美术全部内嵌，没有任何外部依赖，可以直接拖给别人。

开发时用源文件：

```bash
python3 -m http.server 4173
```

浏览器打开 <http://127.0.0.1:4173>。改完源文件后跑 `python3 build.py` 重新打包单文件版（需要 Pillow）。

> 单文件版通过 `file://` 打开时，部分浏览器会禁用 localStorage，此时存档静默失效但游戏照常运行。需要存档就用上面的本地服务。
